# Overview

## Overview

가스센서는 주변 환경에 존재하는 특정 가스를 감지하고, 그 농도 또는 존재 여부를 전기적 신호로 변환하는 핵심 감지 소자입니다.

가스의 종류와 측정 목적에 따라 전기화학식(Electrochemical), 접촉연소식(Catalytic), 반도체식(MOS), 비분산적외선식(NDIR) 등 다양한 검지 기술이 사용되며, 각각의 방식은 감도, 선택성, 측정 범위, 소비전력, 응답 특성 및 적용 환경에서 서로 다른 특징을 가지고 있습니다.

**Sensor Technology**에서는 가스센서의 기본 개념과 발전 과정, 주요 검지 원리를 이해하는 데 필요한 기초 기술을 다룹니다.

***

### 가스센서란?

가스센서의 기본 개념과 역할을 알아보고, 센서에서 발생한 신호가 신호처리 회로와 ADC, MCU를 거쳐 실제 가스 농도로 변환되는 기본적인 측정 시스템의 구조를 살펴봅니다.

### 가스센서의 역사

산업안전과 환경 측정 기술의 발전과 함께 변화해 온 가스 검지 기술의 역사를 살펴봅니다.

초기의 가스 검지 방법부터 접촉연소식, 전기화학식, 반도체식 및 광학식 가스센서가 등장하고 발전해 온 과정을 소개합니다.

### 가스센서 검지 방식

가스센서는 대상 가스의 물리적·화학적 특성에 따라 서로 다른 검지 원리를 사용합니다.

전기화학식(Electrochemical), 접촉연소식(Catalytic), 반도체식(MOS), 비분산적외선식(NDIR) 등 산업용 가스 측정에 널리 사용되는 주요 검지 방식의 원리와 특징을 비교합니다.
